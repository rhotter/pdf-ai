# Readatron Privacy Policy

Effective date: May 5, 2026

Readatron is a Chrome extension that lets you ask questions about PDFs opened in Chrome.

## Data Readatron Handles

Readatron stores the following data locally in Chrome extension storage:

- Your OpenAI API key
- Readatron settings
- Per-PDF chat history
- The PDF URL used to associate a chat with a document

When you ask a question, Readatron sends the current PDF content, your prompt, and relevant chat context to OpenAI so OpenAI can generate an answer. Readatron does not send PDF content to OpenAI until you submit a question.

## How Data Is Used

Readatron uses this data only to provide PDF chat, answer generation, settings, and chat history for the extension.

Readatron does not sell user data, does not use user data for advertising, and does not use user data to determine creditworthiness or for lending purposes.

## Third-Party Services

Readatron uses OpenAI's API to generate answers. Data sent to OpenAI is handled by OpenAI under OpenAI's applicable terms and privacy policies.

## Retention And Control

Your OpenAI API key, settings, and chat history remain in Chrome extension storage on your device unless you remove them, clear extension data, or uninstall the extension.

## Remote Code

Readatron does not load or execute remote JavaScript or WebAssembly. Extension code is included in the packaged extension.

## Contact

For privacy questions, contact the publisher through the Chrome Web Store listing for Readatron.
